# GameCube and Wii settings inventory (our own core)

Generated by `scripts/build-gc-inventory.py` from the settings pulled out of each emulator's
source by `scripts/extract-gc-option-keys.py`. Do not edit by hand: edit
`option-sources/gc/mapping.tsv` (and `same.tsv`) and rerun.

Rule (docs/CORE_OPTIONS_STANDARD.md): our core offers every setting any of these offers, and more.
Settings the app already does for every console (speed, save states, cheats, filters, on-screen
controls, online play, RetroAchievements) stay in the app, not the core.
