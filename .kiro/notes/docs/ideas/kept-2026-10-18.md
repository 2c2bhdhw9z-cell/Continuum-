# Ideas the owner kept (18 October 2026, about 2:40 PM Eastern)

From a list of whole-app ideas. Nothing here is built. Do not start any of the kept ones
unless the owner asks. The widget was a look-only check.

## Kept

**Undo a delete.** Games you delete sit in a bin until the next day. You can put them back.
Nothing is removed for good until that day is up. Saves go with the game, both ways.

**Next game, same console.** While a game is open, jump to the next game on that same console
without going back to the library. The one you leave keeps its auto-save, the same as leaving
it the normal way.

**The game at the top of Home.** You pick which game sits in the big spot. Right now that spot
is just the last game added. The file and the shelves stay as they are.

## Looked into: a Continue widget on the home screen

The idea: a widget with the picture of where you stopped. Tap it and you are back in that game.
Not an icon for every game.

**The tap already works.** `continuum://play?game=<file name>` opens that game (LibraryExtras.swift,
`LaunchLink`). The owner tried it on 17 October through Shortcuts and it passed. Opening the
game the normal way resumes the auto-save. A widget would call that same link.

**The widget itself probably will not show on this phone.** A widget is a second little app
packed inside Continuum (`PlugIns/*.appex`). Feather and ESign, which are how this .ipa is
signed, take one certificate and one profile and apply them to the main app. Feather's author
said that does not set up a widget: the second piece never registers, so Continuum would not
appear in the add-widget list. The same one-profile limit is why the picture cannot be shared
either. The widget runs outside the app and can only read a picture from a shared folder, and
that folder needs an extra permission those certificates do not include.

A real developer account, with a profile per piece, can do it. That needs a computer to refresh
the install. The owner has no computer and will not use one. So this idea is parked. Do not
build it unless the owner gets a signer that keeps widgets.

What would be built, if that ever changes: when you leave a game, copy a small picture and the
game's file name into the shared folder. The widget shows that picture. Tapping it opens
`continuum://play?game=...`. If the signer dropped the widget, the app still installs and plays
exactly as it does now.
