Reference MAME for cArcade's board comparisons (local only: never shipped, never committed).

Binary: /projects/sandbox/.scratch/mame/mame-mame0289/arcaderef
Version: MAME 0.289, built from the mame0289 release tarball (codeload.github.com).
Drivers in it (1608 machines since 27 October 2026, cArcade's second round): every driver in
src/mame/pacman/ and src/mame/galaxian/, src/mame/nintendo/dkong.cpp, and namco/galaga.cpp,
xevious.cpp, digdug.cpp, bosco.cpp, capcom/1942.cpp, konami/timeplt.cpp, pooyan.cpp,
tecmo/bombjack.cpp, capcom/cps1.cpp and snk/neogeo.cpp. In a fresh sandbox run setup-mame-deps.sh
then build-mame.sh (about 40 minutes with 7 jobs).
Built by /projects/sandbox/.scratch/mame/build-mame.sh (SUBTARGET=arcaderef with SOURCES=..., -j2).

Headless use (no X11, no OpenGL; SDL2 here has only its dummy/offscreen video and dummy/disk audio):
  export SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy
  arcaderef <set> -rompath <dir> -video none -sound none -nothrottle -skip_gameinfo \
      -seconds_to_run <n> -wavwrite out.wav -samplerate 192000 \
      -autoboot_script script.lua
Your own test-program ROMs go in <dir>/<set>/ under the driver's file names; MAME runs ROMs with
wrong checksums after a warning. MAME writes cfg/, nvram/, snap/ ... into the current directory,
so run it from a scratch directory of your own.
